# Instagram エージェントキット

あなたの AI エージェント（Claude Code など）がこのフォルダを読むと、Instagram の運用を毎日続けられるようになるキットです。

- 企画を出す → 台本・キャプション・ハッシュタグ・表紙の文字を作る → 予約して投稿する
- 投稿の数字を取る → 週に1回ふり返って、次の企画に活かす
- コメントに返信の下書きを作る（あなたが確かめたものだけ送る）
- 合言葉コメントの人に DM を1通返す（公式の「プライベート返信」）

**費用は、あなたが自分で取る Meta のアプリと、あなたの AI エージェントの利用料だけです。** Instagram の API そのものは無料で使えます。このキットはほかのサーバーに何も送りません。

---

## 最初の10分

1. このフォルダを自分のパソコンに置く（受け取ったリポジトリを clone する）
2. Python 3.11 以上があるか確かめる：`python3 --version`
3. `.env.example` を写して `.env` を作る：`cp .env.example .env`
4. 下の「キーの取り方」で `IG_ACCESS_TOKEN` を取り、`.env` に貼る
5. つながるか見る：
   ```
   python3 scripts/ig_whoami.py          # 送る予定のリクエストが出るだけ（まだ何も起きない）
   python3 scripts/ig_whoami.py --go     # 本当に呼ぶ → user_id と username が出れば成功
   ```
6. 出てきた `user_id` を `.env` の `IG_USER_ID` に貼る
7. 投稿の流れを dry-run で見る（何も送られません）：
   ```
   python3 scripts/ig_check.py drafts/example-reel.md
   python3 scripts/ig_publish.py --kind image --media https://example.com/sample.jpg --caption-file drafts/example-reel.md
   ```
8. AI エージェントに「AGENT.md を読んで、今日の分をやって」と頼む

ここまでで投稿はまだ1本も出ていません。**投稿・返信・DM は、コマンドに `--go` を付けたときだけ** 本当に送られます。

## キーの取り方（Instagram ログインの形・Facebook ページは要りません）

用意するもの：Instagram の **プロアカウント（ビジネス または クリエイター）**。個人アカウントは設定 → アカウントの種類 から無料で切り替えられます。

1. https://developers.facebook.com/ で開発者として登録し、「アプリを作成」
2. ユースケースで Instagram を選び、「Instagram ログインによる API 設定」を開く
3. 「アプリの役割」であなたの Instagram アカウントをテスターに足し、Instagram の側で招待を承認する
   - テスターにするアカウントは公開アカウントにしておく（公式の条件）
4. API 設定の画面で、自分のアカウントの横の「トークンを生成」を押して Instagram にログイン
5. 出てきたトークンを `.env` の `IG_ACCESS_TOKEN` に貼る（**60日で切れます**）
6. 50日目くらいに延ばす：`python3 scripts/ig_token.py refresh --go`（発行から24時間たっていれば延ばせる）

使う権限（スコープ）：
| 権限 | 使うところ |
|---|---|
| instagram_business_basic | アカウント情報・投稿一覧（全部に必要） |
| instagram_business_content_publish | 投稿・予約投稿 |
| instagram_business_manage_insights | 数字を取る |
| instagram_business_manage_comments | コメントの取得・返信・非表示 |
| instagram_business_manage_messages | DM（プライベート返信） |

**自分のアカウントだけに使うなら、アプリ審査は要りません**（標準アクセスで足ります）。他人のアカウントを運用する場合は、アプリ審査とビジネス認証が要ります。

Facebook ページとつないだ形（Facebook ログイン）を使っている人は、`.env` の `IG_HOST=graph.facebook.com` にして、そのトークンと IG ユーザーID を入れてください。

## できること・できないこと（公式ドキュメントで確かめた範囲）

| やりたいこと | できるか | 使う道具 |
|---|---|---|
| 画像・カルーセル（2〜20枚）・リール・ストーリーズの投稿 | できる | `scripts/ig_publish.py` |
| 予約投稿 | API に予約の機能は無い → このキットが時刻を見て出す | `scripts/ig_queue.py` |
| 投稿ごとの数字（表示・リーチ・保存・シェア・リールの平均視聴） | できる（最大48時間遅れる） | `scripts/ig_insights.py` |
| アカウント全体の数字 | できる（一部はフォロワー100人以上から） | `scripts/ig_insights.py` |
| コメントの取得・返信・非表示 | できる | `scripts/ig_comments.py` |
| 合言葉コメントの人へ DM を1通 | できる（コメントから7日以内・1件に1通） | `scripts/ig_private_reply.py` |
| 届いた DM に自動で返事 | 条件つき（下の「DM の決まり」） | このキットではやらない |
| 画像を PNG のまま投稿 | できない（JPEG だけ） | 変換してから |
| ショッピングタグ・フィルター・ストーリーズのスタンプ | できない | アプリで手作業 |
| 他人の投稿の数字・ハッシュタグの中身を大量に集める | このキットではやらない（規約・制限が厳しい） | ― |

公式の上限：
- 投稿は **24時間で50本まで**（`content_publishing_limit` の `quota_total` に今の値が出ます。案内ページには100本と書かれた所もあり、API が返す値を正とします）
- キャプション2200字・ハッシュタグ30個・@タグ20個
- 画像：JPEG・8MB以下・縦横比 4:5〜1.91:1
- リール：MP4／MOV・3秒〜15分・300MB以下
- 画像・動画は **インターネットから見られる URL** に置く（Meta が取りに来ます）。置き場所は自分のサーバー・クラウドの公開バケットなど

### DM の決まり（大事）

- **コメントへのプライベート返信**：1件のコメントに1通だけ・コメントから7日以内。相手が返事をくれたら、そこから24時間は普通にやり取りできる
- **届いた DM への返事**：相手から最後にメッセージが来てから **24時間以内** だけ送れる。人が返す場合の延長（7日）もあるが、このキットは使わない
- 1通は1000バイトまで（日本語なら約330字）
- リアルタイムで返すには Webhook を受けるサーバーが要る。このキットは「10〜15分おきに見に行く」形
- 「コメントしたら必ずプレゼント」のような **反応と引き換えの配布** は Meta のスパムの決まりに触れることがあります。合言葉は「欲しい人が自分から言う」形にとどめ、フォローを条件にしない

## 毎日の動かし方（cron の例）

```
# 10分おきに予約を見て出す
*/10 * * * * cd /path/to/instagram-agent-kit && python3 scripts/ig_queue.py run --go >> data/cron.log 2>&1
# 15分おきに合言葉コメントへ DM
*/15 * * * * cd /path/to/instagram-agent-kit && python3 scripts/ig_private_reply.py --go >> data/cron.log 2>&1
# 毎朝7時に数字を取る
0 7 * * * cd /path/to/instagram-agent-kit && python3 scripts/ig_insights.py --limit 30 --go >> data/cron.log 2>&1
```
`/path/to/` は自分の置き場所に替えてください。

## 中身

```
README.md        このファイル
AGENT.md         エージェントへの指示書（役割・毎日やること・判断の基準・やってはいけないこと・止まったとき）
CLAUDE.md        Claude Code 向け（AGENT.md を読むように）
playbooks/       作業ごとの手順（企画・台本・キャプション・表紙・コメント・DM・ふり返り）
templates/       台本・カルーセル・キャプション・表紙・ふり返りの型
scripts/         API を呼ぶ道具（標準ライブラリだけ・既定は dry-run）
config/          合言葉の設定（例つき）
drafts/          エージェントが作る下書きの置き場
queue/           予約の置き場
data/            数字・ログの置き場（git に入れない）
```

## 困ったとき

| 出たもの | 意味 | やること |
|---|---|---|
| エラーコード 190（トークンが無効） | 期限切れ | 「トークンを生成」でもう一度作る |
| エラーコード 10・200番台（権限のエラー） | 権限が足りない | アプリの設定で上の表の権限が付いているか |
| status_code が ERROR | 動画の形式・URL | MP4/MOV・公開URL・長さを確かめる |
| HTTP 429・エラーコード 4 / 17 / 32（呼びすぎ） | 1時間あけて、件数を減らす |
| `IG_USER_ID がありません` | .env が空 | 「最初の10分」の5〜6 |

## このキットは N-Hack のAIエージェント専用です

このキットは N-Hack の受講生さん専用のプレゼントです。**N-Hack のAIエージェント
（N-Hack のプラグインを入れた Claude Code など）が、このパソコンで動いていること**を
前提にしています。

- どのスクリプトも、最初に `scripts/nhack_gate.py`（門）を通ります。門は、このパソコンに
  N-Hack のAIエージェントの「印」があるかを**読むだけ**で確かめます（ネットにつなぎません・
  何も書き換えません・プラグインには一切触れません）。
- 印が足りない環境では、スクリプトは動かずに止まります（終了コード 2）。この環境でだけ
  動くのが正しい姿です。
- いま N-Hack 環境かどうかは、次のコマンドで確かめられます。

```bash
python3 scripts/nhack_gate.py
```

N-Hack 以外のパソコンにコピーしても動きません。受講生ページ・コンサルチャンネルの案内に
沿ってご利用ください。
