# 04 コメントに返す

## 流れ
1. `python3 scripts/ig_comments.py fetch --media 5 --go`
2. `data/reply-drafts.json` を開き、`reply` が空のものに下書きを書く
3. 持ち主に見せる（初めの2週間は全部）→ OK のものだけ `"approve": true`
4. `python3 scripts/ig_comments.py send`（dry-run で確かめる）→ `send --go`

## 返し方の基準
| コメントの種類 | 返し方 |
|---|---|
| 感想・お礼 | お礼＋その人の言葉を1つ拾って返す（1〜2文） |
| 質問 | 短く答える。長くなるなら「次の投稿で詳しく出します」と書き、企画の候補に足す |
| 合言葉（DM の対象） | コメントには「DMお送りしました」と1行。DM は `ig_private_reply.py` が送る |
| 批判 | 事実の誤りだけ1回丁寧に正す。言い返さない。迷ったら持ち主に回す |
| 宣伝・荒らし・個人攻撃 | 返さない。持ち主の OK で `hide --go` |

## やらないこと
- 全部に同じ文を返す（機械的に見え、制限の引き金になります）
- 1回に20件より多く返す
- 相手の個人情報を聞き出す
