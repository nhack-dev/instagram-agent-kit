# 06 合言葉コメントへの DM

## 公式の条件（変えられない）
- コメント1件に DM は1通だけ・コメントから7日以内
- 相手が DM に返事をしたら、そこから24時間は普通に話せる
- 届いた DM への返事は、相手の最後のメッセージから24時間以内だけ
- 1通1000バイトまで（日本語で約330字）

## 設定
1. `config/keywords.example.json` を写して `config/keywords.json` を作る
2. 合言葉ごとに文を書く（文は `templates/dm-message.txt` の形・ファイルに分けてもよい）
3. 特定の投稿だけにしたいときは `media_ids` に投稿IDを入れる（`data/published.jsonl` にある）

## 動かす
```
python3 scripts/ig_private_reply.py          # 送る相手と文が出るだけ
python3 scripts/ig_private_reply.py --go     # 送る
```
送った記録は `data/private-replies.jsonl`。同じコメントに2回送らない仕組みです。

## 文の決まり
- 1通目で言うのは「お礼」「約束したもの（リンクなど）」「次の一歩を1つ」だけ
- 売り込みを並べない
- 投稿で「コメントで◯◯」と案内するときは、フォローを条件にしない
